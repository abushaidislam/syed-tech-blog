## ১. ভূমিকা এবং মনোরিপো ডকুমেন্টেশন প্যার্যাডক্স (Introduction & The Monorepo Documentation Paradox)

আধুনিক সফটওয়্যার ডেভেলপমেন্টে, জটিল ওয়েব অ্যাপ্লিকেশন, ব্যাকএন্ড সার্ভিস, CLI প্যাকেজ এবং ডাটাবেস ড্রাইভার পরিচালনার ক্ষেত্রে মনোরিপো (Monorepos) একটি প্রধান মানদণ্ডে পরিণত হয়েছে। Turborepo, Nx, এবং pnpm workspaces-এর মতো ফ্রেমওয়ার্ক টিমগুলোকে কোড একই স্থানে রাখতে, টাইপস্ক্রিপ্ট টাইপ শেয়ার করতে এবং একাধিক প্যাকেজজুড়ে অ্যাটমিক কমিক পরিচালনা করতে সাহায্য করে।

তবে, সফটওয়্যার প্রজেক্ট যখন স্কেল করে, তখন একটি হতাশাজনক বৈপরীত্য বা প্যার্যাডক্স দেখা দেয়: **ডকুমেন্টেশন লেয়ারটি অ্যাপ্লিকেশন মনোরিপোর সহযোগী জটিলতার (collateral complexity) জালে বন্দি হয়ে পড়ে।**

```
The Monorepo Bloat Trap:
┌────────────────────────────────────────────────────────────────────────┐
│                        MASSIVE MONOREPO GRAPH                          │
│                                                                        │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────────────────┐  │
│  │ Core Engine  │ ──>│ Auth Service │ ──>│ Database ORM Schemas     │  │
│  └──────────────┘    └──────────────┘    └──────────────────────────┘  │
│          │                                            │                │
│          ▼                                            ▼                │
│  ┌──────────────┐                        ┌──────────────────────────┐  │
│  │  CLI Tooling │                        │ Monorepo Workspace Root  │  │
│  └──────────────┘                        └──────────────────────────┘  │
│                                                       │                │
│                                                       ▼                │
│                                          ┌──────────────────────────┐  │

└────────────────────────────────────────────────────────────────────────┘
```

যখন একজন টেকনিক্যাল রাইটার বা ওপেন-সোর্স অবদানকারী কোনো MDX ফাইলে টাইপো ঠিক করতে চান বা API রেফারেন্সে একটি দ্রুত কোড স্নিপেট যোগ করতে চান, তখন তারা গিগাবাইট আকারের সোর্স কোড ক্লোন করতে বাধ্য হন। স্থানীয়ভাবে ডকুমেন্টেশন সাইটটি চালানোর জন্য তাদের নেটিভ C++ কম্পাইলেশন টুলচেইন ইনস্টল করতে হয়, ডাটাবেস কন্টেইনার বুট করতে হয়, জটিল ওয়ার্কস্পেস গ্রাফ ডিপেন্ডেন্সি সমাধান করতে হয় (`workspace:*`), এবং ৪৫ সেকেন্ডের ডেভেলপার সার্ভার বুট টাইমের মুখোমুখি হতে হয়।

### সংখ্যায় সমস্যাগুলো (The Problem in Numbers)
- **ওয়ার্কস্পেস ডিপেন্ডেন্সির ওজন (Workspace Dependency Weight):** শেয়ার করা ওয়ার্কস্পেস ডিপেন্ডেন্সি এবং ইন্টারনাল বিল্ড ইউটিলিটির কারণে একটি সাধারণ ডকুমেন্টেশন ডিরেক্টরি প্রায়শই ১.২ জিবি+ `node_modules` টেনে আনে।
- **CI/CD পাইপলাইনের লেটেন্সি (CI/CD Pipeline Latency):** ছোট কোনো মার্কডাউন পরিবর্তনের জন্যও ডকুমেন্টেশন বিল্ড ডিপ্লয় করতে Turborepo DAG (Directed Acyclic Graph) পুনরায় মূল্যায়ন করতে হয়, যা বিল্ড পাইপলাইনকে কয়েক মিনিট দীর্ঘ করে তোলে।
- **কাপল্ড রিলিজ সাইকেল (Coupled Release Cycles):** লাইব্রেরি প্যাকেজের অসম্পর্কিত টাইপস্ক্রিপ্ট এররের কারণে ডকস বিল্ড ব্যর্থ হয়, যা জরুরি পাবলিক যোগাযোগ ব্যাহত করে।

### কডওক-এর পরিচয়: স্ট্যান্ডঅ্যালোন ভিশন (Introducing Qodewk: The Standalone Vision)

একটি স্পষ্ট ইঞ্জিনিয়ারিং চাহিদা থেকেই **Qodewk**-এর জন্ম: **শীর্ষস্থানীয় আধুনিক ডকুমেন্টেশন প্ল্যাটফর্মের নান্দনিক ডিজাইন, টাইপ-সেফ MDX পার্সিং এবং গতিশীল ডেভেলপার এক্সপেরিয়েন্স (DX) বজায় রেখেই মনোরিপো আর্কিটেকচার থেকে ডেভেলপার ডকুমেন্টেশনকে আলাদা (decouple) করা।**

Better Auth-এর মতো আধুনিক ওপেন-সোর্স টুল দ্বারা জনপ্রিয় হওয়া ডকুমেন্টেশন ইঞ্জিন আর্কিটেকচার থেকে সংগৃহীত, Qodewk ডকুমেন্টেশনকে একটি স্বাধীন, একক-উদ্দেশ্যমূলক ইঞ্জিন হিসেবে পুনর্কল্পনা করে। এটি Next.js 15 App Router, React Server Components (RSC), কাস্টম MDX পাইপলাইন এবং স্বয়ংক্রিয় CLI এক্সট্র্যাকশন স্ক্রিপ্টকে একত্রিত করে শূন্য-রানটাইম-ব্লোট প্ল্যাটফর্ম প্রদান করে যা মিলিভেকন্ডে বুট হয় এবং সেকেন্ডের মধ্যে ডিপ্লয় হয়।

### ২.১ নিষ্কাশন কৌশল: Next.js + MDX আর্কিটেকচার ডিকাপল করা (Extraction Strategy)

একটি সাধারণ মনোরিপো সেটআপে, ডকুমেন্টেশন সাইটটি ওয়ার্কস্পেস-অভ্যন্তরীণ প্যাকেজ যেমন `@repo/ui`, `@repo/tsconfig`, বা `@repo/utils`-এর উপর নির্ভর করে।

Qodewk-কে একটি স্বায়ত্তশাসিত ফ্রেমওয়ার্কে রূপান্তর করতে, আমরা তিনটি আর্কিটেকচারাল রূপান্তর সম্পন্ন করেছি:

১. **স্বয়ংসম্পূর্ণ UI প্রিমিটিভস (Self-Contained UI Primitives):** এক্সটার্নাল UI লাইব্রেরি রানটাইম ডিপেন্ডেন্সি দূর করে শেয়ার্ড মনোরিপো কম্পোনেন্টগুলোকে ডেডিকেটেড Tailwind CSS প্রিমিটিভ দিয়ে প্রতিস্থাপন করা হয়েছে।
২. **একত্রিত কনটেন্ট প্রসেসিং পাইপলাইন (Unified Content Processing Pipeline):** `next-mdx-remote` এবং `gray-matter` ব্যবহার করে MDX কম্পাইলেশন, ফ্রন্টম্যাটার পার্সিং, সিনট্যাক্স হাইলাইটিং এবং হেডিং এক্সট্র্যাকশনকে একটি একক, উচ্চ-পারফর্মিং কনটেন্ট লোডার লেয়ারে সুবিন্যস্ত করা হয়েছে।
৩. **স্বাধীন অ্যাসেট ম্যানেজমেন্ট (Independent Asset Management):** স্ট্যাটিক মিডিয়া হ্যান্ডলিং বিচ্ছিন্ন করা হয়েছে, যা নিশ্চিত করে যে সমস্ত ইমেজ অ্যাসেট, ফন্ট এবং ওপেন গ্রাফ টেমপ্লেট ওয়ার্কস্পেস পাথের পরিবর্তে স্ট্যান্ডঅ্যালোন রুট আপেক্ষিক হয়ে কাজ করে।

### ২.২ ডিপেন্ডেন্সি স্যানিটাইজেশন: মনোরিপো ওয়ার্কস্পেস রেফারেন্স দূর করা (Dependency Sanitization)

একটি স্ট্যান্ডঅ্যালোন ইঞ্জিন তৈরির সবচেয়ে গুরুত্বপূর্ণ ধাপ হলো **ডিপেন্ডেন্সি স্যানিটাইজেশন**। মনোরিপো `package.json` ম্যানিফেস্টে ওয়ার্কস্পেস স্পেসিফায়ার থাকে:

```json
// BAD: Coupled Monorepo package.json
{
  "dependencies": {
    "@internal/ui": "workspace:*",
    "@internal/auth-core": "workspace:^1.0.0",
    "next": "^15.0.0"
  }
}
```

Qodewk তৈরি করার সময়, আমরা স্বয়ংক্রিয় স্যানিটাইজেশন স্ক্রিপ্ট তৈরি করেছি যা ওয়ার্কস্পেস প্রোটোকল মার্কারগুলোকে স্পষ্ট, প্রোডাকশন-রেডি semver বাউন্ড দিয়ে প্রতিস্থাপন করে অথবা সরাসরি স্থানীয় `src/lib/` ডিরেক্টরিতে ইন্টারনাল ইউটিলিটি ফাংশন যুক্ত করে।

### ৩.১ CLI অটোমেশন ওয়ার্কফ্লো (CLI Automation Workflow)

Qodewk এক্সট্র্যাকশন ওয়ার্কফ্লো তিনটি অপারেশন স্বয়ংক্রিয় করে:
১. **Git Sparse Checkout:** পুরো কমিট হিস্ট্রি বা ভারী অ্যাপ্লিকেশন কোড ফেচ না করেই টার্গেট গিট রিপোজিটরি থেকে কেবল নির্ধারিত ডকুমেন্টেশন ডিরেক্টরি এবং কনফিগারেশন ফাইল পুল করে।
২. **Regex-ভিত্তিক AST এবং ডিপেন্ডেন্সি স্যানিটাইজেশন:** ওয়ার্কস্পেস ইম্পোর্ট স্ট্রিপ করতে এবং ফাইল পাথ প্যাচ করতে `package.json`, `tsconfig.json`, এবং ইম্পোর্ট স্টেটমেন্ট স্ক্যান করে।
৩. **Pnpm লকফাইল রি-রেজোলিউশন:** জিরো ওয়ার্কস্পেস গ্রাফ লিংকসহ একটি তাজা, আইসোলেটেড `pnpm-lock.yaml` তৈরি করে।

নিচে এক্সট্র্যাকশনের সময় Qodewk CLI দ্বারা ব্যবহৃত অন্তর্নিহিত Bash ও Node.js অটোমেশন স্ক্রিপ্ট দেওয়া হলো:

```bash
#!/usr/bin/env bash
set -euo pipefail

# Qodewk CLI Extraction Engine v1.0.0
REPO_URL="https://github.com/abushaidislam/Qodewk.git"

# Configure sparse checkout paths

echo "docs/" >> .git/info/sparse-checkout
```

#### ২. লোকাল MDX কনটেন্ট পার্সার (`src/lib/docs.ts`)

এই পাইপলাইনটি লোকাল `.mdx` ফাইল পার্স করে, কাস্টম ফ্রন্টম্যাটার মেটাডেটা এক্সট্র্যাক্ট করে এবং স্টিকি টেবিল অফ কনটেন্টসের জন্য হেডিং স্বয়ংক্রিয়ভাবে কম্পাইল করে।

```typescript
import fs from "fs";
import path from "path";
import matter from "gray-matter";

const DOCS_DIRECTORY = path.join(process.cwd(), "content", "docs");

export interface DocHeading {
  id: string;
  title: string;
  level: number;
}

export interface DocFrontmatter {
  title: string;
  description: string;
  category?: string;
  order?: number;
  updatedAt?: string;
}

export interface DocPost {
  slug: string;
  frontmatter: DocFrontmatter;
  content: string;
  headings: DocHeading[];
}

// Convert string header into clean URL slug ID
export function slugify(text: string): string {
  return text
    .toLowerCase()
    .trim()
    .replace(/[^\w\s-]/g, "")
    .replace(/[\s_-]+/g, "-")
    .replace(/^-+|-+$/g, "");
}

// Extract H2 and H3 headings for interactive Table of Contents
export function extractHeadings(content: string): DocHeading[] {
  const headingRegex = /^(#{2,3})\s+(.+)$/gm;
  const headings: DocHeading[] = [];
  let match;

  while ((match = headingRegex.exec(content)) !== null) {
    const level = match[1].length;
    const rawTitle = match[2].trim();
    const cleanTitle = rawTitle.replace(/[*_`]/g, "");
    const id = slugify(cleanTitle);

    headings.push({ id, title: cleanTitle, level });
  }

  return headings;
}

// Read single MDX document by slug
export function getDocBySlug(slug: string): DocPost | null {
  try {
    const filePath = path.join(DOCS_DIRECTORY, `${slug}.mdx`);
    if (!fs.existsSync(filePath)) return null;

    const fileContent = fs.readFileSync(filePath, "utf-8");
    const { data, content } = matter(fileContent);

    return {
      slug,
      frontmatter: data as DocFrontmatter,
      content,
      headings: extractHeadings(content),
    };
  } catch (error) {
    console.error(`Error loading doc for slug ${slug}:`, error);
    return null;
  }
}
```

```tsx
"use client";

import { useState } from "react";

interface CodeBlockProps {

  language?: string;
  filename?: string;

          <span>{filename}</span>
          <span className="uppercase text-[#cc785c]">{language}</span>
        </div>
      )}
      <div className="relative p-4 overflow-x-auto font-mono text-[#e6dfd8] leading-relaxed">
        <button
          onClick={copyToClipboard}
          className="absolute right-3 top-3 flex h-8 w-8 items-center justify-center rounded-md border border-[#3d3a36] bg-[#252320] text-[#a09d96] opacity-0 transition-opacity group-hover:opacity-100 hover:text-[#faf9f5]"

        </button>
        <pre><code>{code}</code></pre>
      </div>
    </div>
  );
}
```

Qodewk তৈরি করে প্রমাণিত হয়েছে যে একটি এন্টারপ্রাইজ অ্যাপ্লিকেশন মনোরিপোর পুরো ওজন বহন করার প্রয়োজন ডকুমেন্টেশন ইঞ্জিনের নেই। Next.js এবং MDX-কে একটি ডিকাপল্ড আর্কিটেকচারে এক্সট্র্যাক্ট করার মাধ্যমে, ডেভেলপার ডকুমেন্টেশন আরও দ্রুত তৈরি করা যায়, অবদান রাখা সহজ হয় এবং হোস্ট করা উল্লেখযোগ্যভাবে সাশ্রয়ী হয়।

### স্ট্র্যাটেজিক রোডম্যাপ: Qodewk-এর পরবর্তী পদক্ষেপ

১. **নেটিভ প্লাগইন ইকোসিস্টেম:** স্বয়ংক্রিয় OpenAPI/Swagger স্পেসিফিকেশন রেন্ডারিং, ইন্টারেক্টিভ কোড স্যান্ডবক্স (Sandpack), এবং Mermaid ডায়াগোরামের জন্য প্লাগেবল rehype এবং remark এক্সটেনশন।
২. **জিরো-সার্ভার সার্চ ইনডেক্সিং:** এক্সটার্নাল সার্চ API কী ছাড়াই বিল্ড টাইমে লাইটওয়েট, স্ট্যাটিক সার্চ ইনডেক্স তৈরি করতে Pagefind এবং FlexSearch-এর সাথে নেটিভ ইন্টিগ্রেশন।
৩. **AI-পাওয়ার্ড RAG ডকস সার্চ:** কন্টেক্সট-অ্যাওয়ার সেমান্টিক ডকুমেন্টেশন সার্চ ব্যবহার করে লোকাল এমবেডিং এবং ফ্রন্টিয়ার LLM (Gemini Flash / Claude 3.5), যা ডেভেলপারদের ডকস হেডারের ভেতরেই সরাসরি স্বাভাবিক প্রশ্ন জিজ্ঞাসা করার সুযোগ দেয়।
৪. **অটোমেটেড CI সিঙ্ক ওয়ার্কফ্লো:** GitHub Actions যা মনোরিপো সোর্স রিপো থেকে মার্কডাউন পরিবর্তনগুলোকে রিয়েল টাইমে স্ট্যান্ডঅ্যালোন Qodewk ডিপ্লয়মেন্ট ইনস্ট্যান্সে স্বয়ংক্রিয়ভাবে মিরর করে।
